# React Naver Map

## Introduce

네이버 지도 API를 리액트에서 간편하게 사용할 수 있도록 래핑한 라이브러리 입니다.

NaverAPI 생성 계획은 다음과 같습니다. (배포시 제거할 것)

- 지도 (1주차)
  - 언어 설정
  - 지도 생성 및 기본 동작
  - 지도 유형
  - 지도 투영과 좌표 체계
- 이벤트 (2주차)
  - 이벤트 등록 및 제거 (이벤트 등록에 필요한 타입 정의)
- 컨트롤 (3주차)
- 데이터 표시 (4,5주차)
- 오버레이 (6, 7주치)
- 라이브러리 배포
